# Codexプロンプトテンプレート集

このドキュメントは、Codexに作業依頼するときに使い回せるプロンプト例をまとめたものです。  
Issue番号、ブランチ名、変更してよいファイル、変更してはいけないファイルを明確に書くと、作業範囲をずらさずに依頼しやすくなります。

## 基本のCodex依頼テンプレート

```text
GitHubリポジトリ investment-memo-site2 の Issue #XX に対応してください。

現在の作業ブランチ <branch-name> 上で作業してください。

目的：
<何を実現したいか>

作業内容：
- <具体的な作業1>
- <具体的な作業2>
- <具体的な作業3>

変更してよいファイル：
- <file-name>

変更してはいけないファイル：
- <file-name>

制約：
- 新しいファイルは追加しないでください。
- JavaScriptは使わないでください。
- 既存のリンク先やテーブル構造を壊さないでください。

完了後：
- 変更内容を要約してください。
- 変更したファイルを一覧で教えてください。
- 必要な確認結果を報告してください。
```

## READMEだけを修正するテンプレート

```text
GitHubリポジトリ investment-memo-site2 の Issue #XX に対応してください。

現在の作業ブランチ <branch-name> 上で作業してください。

目的：
README.md の説明を現在の実装内容と一致させてください。

作業内容：
- README.md 全体を確認してください。
- 現在の機能、ページ構成、サイト構成図に矛盾があれば修正してください。
- 過去の作業履歴として残す記述と、現在仕様として直す記述を区別してください。

変更してよいファイル：
- README.md

変更してはいけないファイル：
- index.html
- stocks.html
- earnings.html
- trade-notes.html
- risks.html
- style.css

制約：
- HTML/CSS/JavaScriptは変更しないでください。
- 新しいファイルは追加しないでください。

完了後：
- 変更内容を要約してください。
- 変更したファイルを一覧で教えてください。
```

変更してよいファイル：
- index.html
- stocks.html
- earnings.html
- trade-notes.html
- risks.html
- style.css
- README.md

制約：

## Codexの差分レビュー時のチェックリスト

```text
次の内容を確認して、確認結果を報告してください。

- 指定された作業ブランチ上で作業しているか
- 変更ファイルが許可された範囲に収まっているか
- 新規ファイルが意図せず追加されていないか
- JavaScriptやscriptタグが追加されていないか
- 既存のナビゲーションリンク先が変わっていないか
- README.md の説明が実装内容と一致しているか
- HTMLのテーブル列数がヘッダーと各行で一致しているか
- CSSのclass名が意味のある名前になっているか
- 過去の作業履歴と現在仕様の説明が混ざっていないか
```

## Codexに修正指示を出すときの例文

### デザインを控えめにしたい場合

```text
現在のデザインが少し目立ちすぎます。
既存のサイトデザインに合わせて、背景色・余白・文字サイズを控えめに調整してください。
JavaScriptや新規ファイルは追加しないでください。
```

### READMEの説明を直したい場合

```text
実装とREADMEが一致しているか確認してください。
矛盾があればREADMEだけ修正してください。
HTML/CSS/JavaScriptは変更しないでください。
```

### 変更範囲を確認したい場合

```text
今回の差分を確認してください。
変更ファイル、変更内容、変更してはいけないファイルに差分がないかを報告してください。
```

### JavaScript未使用を確認したい場合

```text
JavaScriptを使っていないことを確認してください。
scriptタグ、.jsファイル、新規JavaScriptコードが追加されていないかを報告してください。
```

## READMEと実装の整合性チェック用テンプレート

```text
README.md と現在の実装内容が一致しているか確認してください。

確認してほしいこと：
- README.md の「現在の機能」が実際のHTML/CSSと一致しているか
- README.md の「ページ構成」が実際のファイル構成と一致しているか
- サイト構成図に存在しないファイルや不足しているファイルがないか
- トップページの説明が index.html の実装と一致しているか
- 専用ページの説明が stocks.html、earnings.html、trade-notes.html、risks.html と一致しているか
- 過去の作業履歴として残す記述と、現在仕様として修正すべき記述が区別されているか

対応方針：
- 矛盾がなければ、確認結果だけ報告してください。
- 矛盾があれば、README.md だけ修正してください。
- HTML/CSS/JavaScriptは変更しないでください。
- 新しいファイルは追加しないでください。
```
