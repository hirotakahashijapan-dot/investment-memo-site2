# 投資分析メモサイト

## 概要

日々の市場状況、注目銘柄、売買候補、リスク要因、ToDoを整理するためのシンプルなWebサイトです。

## 公開URL

GitHub Pagesで公開したサイトはこちらです。

https://hirotakahashijapan-dot.github.io/investment-memo-site2/

## 目的

このリポジトリは、GitHubの基本操作を練習するために作成しました。

また、投資判断の前提条件、買い理由、追加購入条件、撤退条件を明文化することで、感情的な売買を避け、後から判断の妥当性を振り返れるようにすることも目的としています。

主に以下の操作を学習します。

- リポジトリ作成
- ファイル作成
- コミット
- ブランチ作成
- Pull Request
- レビュー修正
- マージ
- 不具合修正

## 使用技術

- HTML
- CSS

## 現在の機能

- 今日の市場メモを表示
- 注目銘柄を表形式で表示
- 決算予定を表形式で表示
- 売買候補を表示
- 売買判断メモを表形式で表示
- リスク要因を表示
- 今日のToDoを表示

## 今後追加したい機能

- デザインを改善する


## 今回追加した機能

### 注目銘柄テーブル

- 注目銘柄セクションをリスト形式から表形式に変更
- 銘柄名、ティッカー、注目理由、確認ポイント、優先度を表示
- 表を見やすくするためのCSSを追加

### 売買判断メモ

- 売買判断メモセクションを追加
- 対象銘柄、投資シナリオ、買い理由、追加購入条件、売却・撤退条件、確認すべきリスクを表示
- 横に広い表でも見やすいように、狭い画面向けのCSSを追加

### 決算予定

- 決算予定セクションを追加
- 銘柄名、ティッカー、決算予定日、決算前の注目ポイント、前回決算の評価、今回確認する項目、決算後の判断を表示
- 決算前後の確認ポイントを整理できるように変更

## 開発プロセス

このトレーニングでは、以下の流れで開発を進めます。

1. 要求仕様を整理する
2. 簡単な設計を行う
3. 初期実装を行う
4. ブランチを作成して機能追加する
5. Pull Requestを作成する
6. レビュー修正を行う
7. mainブランチにマージする
8. 不具合修正を行う
